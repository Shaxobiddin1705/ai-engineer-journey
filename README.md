## 🔁 How I work

- **Every day:** 10 min reading → 40 min coding → 10 min log + commit
- **Rule:** 30% reading, 70% coding. A day without code doesn't count.
- **Sunday:** weekly review with a short summary in English
- **Measure everything:** not "it works better", but "accuracy 72% → 88%"
