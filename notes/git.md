# Git Cheat-Sheet

> Oxirgi yangilanish: 2026-11-04

## 1. Kundalik buyruqlar
| Buyruq | Nima qiladi | Qachon ishlataman |
|---|---|---|
| `git init` | git ni initialize qiladi | Yangi loyiga yaratilganda birinchi git ni qo'shib olish uchun ishlatiladi |
| `git add` | git ga file qo'shadi | Branchda commit/push qilinmagan o'zgarishlar bo'lsa git ga qo'shishda yordam beradi |
| `git add .` | git ga barcha o'zgarishlarni qo'shadi | Agar har bir file nomini yozib chiqmoqchi bo'lmasak bittada hammasini gitga qo'shida |   
| `git commit -m "Your commit"` | qilingan o'zgarishlarga commit qoldiradi | git ga o'zgarishlarni qo'shganimizdan keyin unga kamintariya qoldirish uchun |
| `git push` | git branchga o'zgarish va commit ni push qiladi | commit qilib bo'lgandan keyin branchga barcha o'zgarishlarni push qilish uchun |


## 2. Branch va merge
| Buyruq | Nima qiladi | Qachon ishlataman |
|---|---|---|
| `git switch branch_name` | Mavjud branch ga o'tish | Qachonki bir branch dan 2-branch ga o'tish uchun |
| `git switch -c branch_name`| Yangi branch yaratadi va unga o'tadi | Bizga yangi branch yaratish va shu vaqtni o'zida o'tish uchun ishlatiladi |
| `git merge` | 2-branch ni 1-branchga merge qiladi | Ikkita branch ni birlashtirish uchun|
